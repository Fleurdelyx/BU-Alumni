# **App Name**: BaliuagU Alumni Connect

## Core Features:

- Alumni Questionnaire: A dynamic form for alumni to submit their post-graduation information.
- Alumni Directory: A searchable directory of alumni who have participated in the study, with privacy settings.
- Data Visualization: Interactive charts and graphs to display aggregated data on alumni career paths, course relevance, etc.
- User Account Management: Settings for avatar customization, dark mode toggle, and secure account deletion with confirmation.
- Authentication: Firebase Authentication integration for secure user sign-in and account management.
- Data Storage: Firestore database to securely store alumni responses, user profile information, and site data.
- BUddy AI Chatbot: An AI chatbot tool to answer user questions about the website and provide guidance on completing the questionnaire.

## Style Guidelines:

- Primary color: Medium green (#4C992D) to represent growth and success.
- Background color: Light green (#E0F2E7) to provide a soft and clean backdrop.
- Accent color: Dark green (#004011) to create visual interest for buttons.
- Headline font: 'Goudy Std Old Style Roman' serif, for a classic and elegant appearance, especially in headers and titles.
- Body font: 'PT Sans' sans-serif, for the main body of the website, especially to allow the dark/light modes to look natural; contrasts well with the serif headline font.
- Use of the Baliuag University logo throughout the website where appropriate.
- Responsive design for optimal viewing experience across both PC and mobile browsers.
- Subtle transitions and animations to provide smooth user interactions when navigating the site and viewing data visualizations.
